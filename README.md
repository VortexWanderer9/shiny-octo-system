# React Concepts Academy

An interactive learning platform covering 16 core React concepts, each with a live working demo and a short code excerpt.

## Setup

npm install
npm run dev

Then open the local URL Vite prints (usually http://localhost:5173).

## Build

npm run build

Output goes to dist/. Preview it with:

npm run preview

## Stack

- Vite
- React 18
- Tailwind CSS
- lucide-react (icons)

## Structure

- src/App.jsx — the whole app: lesson registry, sidebar nav, and all 16 demo components
- src/main.jsx — React entry point
- src/index.css — Tailwind directives
